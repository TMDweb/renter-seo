Approved by Mr. Mohamed on Sep 7, 2026. Build it. What to do (Paulo)

  1. Create a new page at slug return-policy: https://renter.net/ar/return-policy/ (and /en/return-policy/ with the same Arabic content for now; the English text can follow later).
  2. Use the same page layout as the FAQ page (header, footer, typography), agreed in the meeting. Paste the content below into it. Do not add the page to any menu or navigation.
