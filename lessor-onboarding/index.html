Popup spec

These are the first-time popups Paulo described in the call: a short message on each step of add-product, shown once.

RuleDetail
Who sees itA user in lessor mode who has 0 items and no finished guide record. Web, Arabic and English. The app can use the same JSON later.
When it showswelcome shows on the lessor dashboard, first visit. Its button opens add-product. Each other popup shows when its step first comes on screen. quantity is on the same screen as name_description, so it shows right after that popup closes.
ButtonsOne main button and one text button. The main button is «التالي» when the next popup is on the same screen, and «فهمت» when the user must now fill the step. The JSON gives this in primary. The text button is «تخطي».
Dismiss ruleThe main button, the X, the Esc key and a tap outside all close the popup and mark that step as seen. «تخطي» closes it and stops all later popups. A published first item also stops the guide. A seen step does not show again.
localStorage keyrenter_lessor_guide_v1:<userId>, one record per user on the device. Change v1 to v2 only when new text must show again to all users.
Value{"seen":["welcome","category"],"done":false,"skipped":false}. Set done to true after review_publish closes or the item is published. Set skipped and done to true on «تخطي».
New devicelocalStorage is empty on a new device. The "0 items" rule stops the guide for a lessor who already has an item. If localStorage is blocked, keep the record in memory for the visit.
Phone, under 768 pxA bottom sheet, full width, above the safe area, at most 60% of the screen height with its own scroll. Scroll the field it explains into view above the sheet. The main button is full width and 48 px high. Do not put focus in a text field, so the keyboard stays closed. Do not open a popup while the keyboard is open.
DesktopA box 360 px wide next to the field it explains, with a small arrow. In Arabic it opens on the left of the field, in English on the right. If the field is not in view, show it in the centre.
Step countShow «الخطوة 3 من 10» on top of each popup, with Western digits. welcome has no count.
Accessrole="dialog", aria-modal="true", aria-labelledby on the title. Focus goes to the main button, and goes back to the step when the popup closes. No motion when the user asks for reduced motion.
Show againOptional: a small link «عرض الدليل» (Show guide) in the add-product header clears the record and starts from the current step.
