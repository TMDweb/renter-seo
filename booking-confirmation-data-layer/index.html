Developer action: expose confirmed bookings to GTM

The current /ar/payment/ trigger is invalid; that URL is a 404.

Push this event only after the backend confirms a successful booking/payment. 
window.dataLayer = window.dataLayer || [];
window.dataLayer.push({
  event: "booking_confirmed",
  transaction_id: String(booking.id),
  value: Number(booking.total),
  currency: "SAR"
});

Rules

  • Push once per successful booking.
  • Never push on page load, button click, failed payment, or cancelled payment.
  • transaction_id must be unique and stable.
  • If payment succeeds inside the cross-origin iframe, send a validated success message to the parent page, then push there.

Done when

  • Successful test: one booking_confirmed event.
  • Failed test: zero events.
  • Refresh/back: no duplicate event.
