Blog schema: the blocks for Paulo

READYSaiaf promised Paulo the blog schema in the Oct 11 meeting. It is complete and ready to copy.

In short

What it is
The hidden code blocks (JSON-LD) that describe each blog page to Google: the article, its author and dates, and the page path.
Where the code is
Section 3 of the blog ticket: complete JSON-LD blocks with one helper function. Two scripts per article: the article block and the breadcrumb block.
When
Paulo asked if it can wait. It should ship with the launch. If it waits, it must go live in the first week.
Rules
The publisher points to the Organization block that is already on the home page; do not repeat it. The last breadcrumb entry has no link. No FAQ block.
Done when
The Rich Results Test finds "Article" and "Breadcrumbs" on a staging article with no errors.
