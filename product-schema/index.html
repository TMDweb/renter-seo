Rules that stay in force (all doc-verified)

  • price is a JSON number; the API sends a string, cast it.
  • availability: availability_status AVAILABLE → https://schema.org/InStock; UNAVAILABLE → https://schema.org/OutOfStock. Never drop offers.
  • Lease terms: one UnitPriceSpecification per available term; hourly → HUR, daily → DAY, weekly → WEE, monthly → MON; a fixed term gets none. offers.price = the daily price when it exists, else the lowest term.
  • Reviews: when review_summary.review_count ≥ 1, add aggregateRating (ratingValue + reviewCount) and the review array; author MUST be {"@type": "Person", "name": "…"}, never a bare string. Zero reviews: omit both. This is already live and accepted; keep it.
  • Do not add: brand, gtin (no source field; never derive from the title), priceValidUntil (a past date suppresses the snippet), return/shipping fields (merchant-listing only).
  • English product pages: same block with the /en/ canonical and translated text.

How to render the block (Next.js App Router)

Render in the server component (page.tsx), as a native <script> in the returned JSX. Not next/script, not the metadata export, never from useEffect. The block must be visible in view-source with JavaScript off. Escape exactly like this, with one shared helper:

<script
  type="application/ld+json"
  dangerouslySetInnerHTML={{{{
    __html: JSON.stringify(jsonLd).replace(/</g, '\\u003c'),

Build the object conditionally; never emit null (it fails validation, while dropped undefined is safe). Reference: nextjs.org JSON-LD guide.
