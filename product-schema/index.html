How to build every field (the generalization)

One template, these sources. Apply it to all 2,000+ products; nothing is per-product manual work.

JSON-LD fieldAPI sourceTransform
nametitleas is, trimmed
descriptiondescriptionstrip tags, decode entities, collapse whitespace
imagepost_images[].imageall of them, in order (already done)
skuidcast to string
url and offers.urlthe canonical URL of the pagethe same value in both; the same function that fills rel="canonical"
offers.pricepost_lease_terms[] where type = "available"JSON number. The daily price when a daily term exists, else the lowest-priced term
offers.availabilityavailability_statusAVAILABLE → https://schema.org/InStock, UNAVAILABLE → https://schema.org/OutOfStock. Never drop offers
priceSpecification[]one entry per available lease termhourly → HUR · daily → DAY · weekly → WEE · monthly → MON · fixed → no entry (already done; keep it)
aggregateRating + reviewreview_summaryonly when review_count ≥ 1; author is a {"@type": "Person", "name": …} object, never a bare string (already done; keep it)

Do not add: brand, gtin (no source field; never derive from the title), priceValidUntil (a past date suppresses the snippet), return or shipping fields (merchant-listing only). English pages: same template with the /en/ canonical and translated text.

How to render the block (Next.js App Router)

Render in the server component (page.tsx), as a native <script> in the returned JSX. Not next/script, not the metadata export, never from useEffect. The block must be visible in view-source with JavaScript off. Escape exactly like this, with one shared helper:

<script
  type="application/ld+json"
  dangerouslySetInnerHTML={{{{
    __html: JSON.stringify(jsonLd).replace(/</g, '\\u003c'),
  }}}}
/>

Build the object conditionally; never emit null (it fails validation, while dropped undefined is safe). Reference: nextjs.org JSON-LD guide.
