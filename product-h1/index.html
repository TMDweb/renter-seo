Product pages: the visible product name must be the H1

MOSTLY DONEChecked Nov 1, 2026 on all 1,430 products in the sitemap: changes 2 and 3 are live. The hidden H1 is gone from every product page, and the visible product name is the H1 on 1,429 of 1,430. 1,410 pages have exactly one H1. 20 pages have a second H1 that comes from the lessor's own description text (change 4, below). The home page H1 is still hidden; that is on the home page ticket.

In short

What is wrong
On Oct 18 every product page had one H1, but it was hidden from visitors (class="hidden"), and the visible name was a paragraph. That is fixed. Left: 20 products have a second H1 inside the product description.
Why it matters
Google's spam policies name text hidden with CSS as "hidden text" when it is there only for search engines. Product pages bring most of the site's Google clicks.
Done so far
Change 1 is live since Sep 29: the section labels (الوصف، السعر، …) are H2 again. Changes 2 and 3 are live on Nov 1: the visible name is the H1, and the hidden H1 is deleted. English pages show the English name as the H1, for example /en/product/2545/ shows "Canon 4000D camera".
The fix
One small change remains: a heading inside the description text prints as H2, never as H1 (change 4).

Dev team. Paulo and Jan decide who takes it.

Change 4: headings inside the description print as H2

The description comes from the lessor's text editor and is printed as HTML. When a lessor uses the editor's biggest heading, the page gets a second H1. In the component that prints the description, change every <h1 in the description HTML to <h2 before it is printed, and drop headings that hold no text:

const descriptionHtml = (post?.description ?? "")
  .replace(/<h1(\s|>)/gi, "<h2$1")
  .replace(/<\/h1>/gi, "</h2>")
  .replace(/<h2[^>]*>(\s|&nbsp;)*<\/h2>/gi, "");

Better still, remove the H1 button from the description editor, so new descriptions cannot add one.

Changes 1 to 3 (all done, kept for reference)

File paths and line numbers come from the June copy of the repository. The lines can have moved since then.

Change 1: section labels back to H2 (done, live since Sep 29)

File: src/components/product_section_container/index.tsx. This component prints the section labels (الوصف، السعر، …). Today it prints them as <h1>. It must print <h2>, as it did in June:

{title && <h2>{title}{subtitle && <span className={`${styles.subtitle}`}>{subtitle}</span>}</h2>}

If productsectioncontainer.module.css styles the label as h1, change that selector to h2 so the look stays the same.

Change 2: the visible product name becomes the H1 (done, live Nov 1)

File: src/sections/product_details_section/index.tsx (line 289 in June). Today the name is a paragraph:

<div className={`${styles.productdetail_product_title}`}>
    <p>
        {post?.title ? post?.title : ""}
    </p>
</div>

Replace it with:

<div className={`${styles.productdetail_product_title}`}>
    <h1>
        {post?.title ? post?.title : ""}
    </h1>
</div>

Add this rule to src/sections/product_details_section/productdetailssection.module.css. The heading then keeps the current font, size and spacing:

.productdetail_product_title h1 {
    font: inherit;
    color: inherit;
    margin: 0;
}

Change 3: delete the hidden H1 (done, live Nov 1)

File: src/app/[locale]/product/[id]/[title]/page.tsx (line 146 in June). Delete this line:

<h1 className="hidden">{rawProduct?.title} للايجار بالسعودية</h1>

Nothing is lost. "للايجار بالسعودية" stays in the page title (the <title> tag), which Google uses for the result title.
