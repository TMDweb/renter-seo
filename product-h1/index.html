REGRESSIONChecked Sep 27, 2026 on all 968 live Arabic product pages in the sitemap: 966 of them have 4 to 7 main headings (H1). In the June code this was correct.

Product pages: the product name must be the one main heading

In short

What is wrong
Every product page has 4 to 7 main headings (H1). They are the section labels الوصف، السعر، الموقع، شاركنا رأيك and, on some products, إضافات اختيارية. The only H1 with the product name is hidden, so visitors never see it.
Why it matters
Google reads the main heading to learn what a page is about. Today it reads the same generic labels on every product page. Product pages bring 61% of the site's Google clicks (361 of 592 in the 28 days to Sep 24). Google's spam policies also name text hidden with CSS as "hidden text" when it is there only for search engines.
The fix
Three small code changes: the section labels go back to H2, the visible product name becomes the H1, and the hidden H1 is deleted.
Owner
Dev team. Paulo and Jan decide who takes it.
Done when
Every product page has exactly one H1, and it is the visible product name. The check command is at the end of this page.

The fix: 3 changes

File paths and line numbers come from the June copy of the repository. The lines can have moved since then.

Change 1: section labels back to H2

File: src/components/product_section_container/index.tsx. This component prints the section labels (الوصف، السعر، …). Today it prints them as <h1>. It must print <h2>, as it did in June:

{title && <h2>{title}{subtitle && <span className={`${styles.subtitle}`}>{subtitle}</span>}</h2>}

If productsectioncontainer.module.css styles the label as h1, change that selector to h2 so the look stays the same.

Change 2: the visible product name becomes the H1

File: src/sections/product_details_section/index.tsx (line 289 in June). Today the name is a paragraph:

<div className={`${styles.productdetail_product_title}`}>
    <p>
        {post?.title ? post?.title : ""}
    </p>
</div>

Replace it with:

<div className={`${styles.productdetail_product_title}`}>
    <h1>
        {post?.title ? post?.title : ""}
    </h1>
</div>

Add this rule to src/sections/product_details_section/productdetailssection.module.css. The heading then keeps the current font, size and spacing:

.productdetail_product_title h1 {
    font: inherit;
    color: inherit;
    margin: 0;
}

Change 3: delete the hidden H1

File: src/app/[locale]/product/[id]/[title]/page.tsx (line 146 in June). Delete this line:

<h1 className="hidden">{rawProduct?.title} للايجار بالسعودية</h1>

Nothing is lost. "للايجار بالسعودية" stays in the page title (the <title> tag), which Google uses for the result title.

Done when

Run this after the deploy. It prints every H1 on the page:

curl -s https://renter.net/ar/product/2545/kamyra-kanwn-4000d/ | grep -o '<h1[^>]*>[^<]*'
