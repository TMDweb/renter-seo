Root Sitemap

/sitemap.xml is a sitemap index. It contains only <sitemap> entries that point to the eight XML files. It does not contain page URLs directly.

The eight child XML files are the URL-list files. Each one uses <urlset> and contains the canonical URLs for one language and one URL type.

What Goes In Each File

  • 1
    Products: public product detail URLs only, such as /ar/product/{id}/{slug} and /en/product/{id}/{slug}.
  • 2
    Pages: public static pages, such as home, about, FAQ, contact, privacy, terms, cancellation policy, and help information pages if they are intended to rank.
  • 3
    Product categories: top-level public category landing pages, such as /ar/properties/ and /en/cars-and-vehicles/.
  • 4
    Product subcategories: public category child pages, such as /ar/properties/apartments/ and /en/equipment-and-tools/generators/.

Implementation Checklist

  • 1
    Every XML URL returns 200 with Content-Type: application/xml.
  • 2
    A sitemapindex file contains only sitemap XML links. A urlset file contains only page URLs.
  • 3
    Use absolute canonical URLs in <loc>. Production files should use https://renter.net/; staging should stay blocked or clearly test-only.
  • 4
    Do not include private, account, booking, payment, chat, search-result, item-management, or edit-product URLs.
  • 5
    Use W3C date or datetime for <lastmod>, for example 2026-07-03 or 2026-07-03T00:14:45+03:00. Omit it if it is not reliable.
  • 6
    Each AR/EN URL pair should include reciprocal hreflang alternates, including a self-reference.
  • 7
    If any URL-list file exceeds 50,000 URLs or 50 MB uncompressed, split that one file into paginated URL-list files and list those final files directly in the relevant index.
